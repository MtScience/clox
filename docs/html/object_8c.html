static

Allocates an Obj.

Takes an amount of memory to be allocated and an ObjType associated with that memory, performs an allocation, sets the type and registers the allocated memory with a garbage collector.

The result of this function is supposed to be cast to a specific object pointer type.

Parameters
[in]gcNon-NULL pointer to a garbage collector that will manage the object.
[in]sizeThe size of the memory block to be allocated in bytes.
[in]typeThe type tag of the requested object.
Returns
The pointer to the allocated object.

Allocates and fills an ObjString.

This function creates a new ObjString on the heap, initializes it and registers it in the virtual machine's VM::strings table.

static

The FNV-1a hash function.

Implements the Fowler—Noll—Vo hashing algorithm (32-bit version). In this project it is used for hashing strings, but can be used for any value, e.g. with a union:

union {
int num;
unsigned char[sizeof(int)] bytes;
} value = { .num = number };
hashString(sizeof(int), value.bytes);
