ObjFunction * compile ( VM vm[static 1],
char const * source )

Compiles a piece of Lox source code.

Takes a VM and a string containing the code to be compiled. Returns a pointer to an object that represents a Lox function. Each call sets up its own scanner, parser, compilation state etc.

Parameters
[in,out]vmNon-NULL pointer to the VM that will execute the compiled code.
[in]sourceThe source code to be compiled.
Returns
The pointer to an ObjFunction that contains the compiled code or nullptr in case compilation failed.
