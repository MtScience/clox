Prints an instruction with an argument.

This function defines the output format for instructions that refer to bytes somewhere else in the chunk's code (OP_GET_LOCAL, OP_CALL, etc.). The format is:

[command name] [argument's index in the code]

E.g., for an instruction loading a local variable, whose value is located at index 1 in the chunk's code, this function would produce this output:

OP_GET_LOCAL 1
Parameters
[in]nameA C string representing the command name.
[in]chunkNon-NULL pointer to the chunk containing the instruction to be printed.
[in]offsetOffset of the instruction from the beginning of the chunk.
Returns
The offset of the next instruction (offset + 2).

Prints a constant instruction.

This function defines the output format for instructions that refer to various constants (OP_CONSTANT, OP_GET_PROPERTY etc.). The format is:

[command name] [argument's index in the constant table] '[argument's value]'

E.g., for an instruction loading a value 10, located at index 1 in the chunk's constant table, onto the stack this function would produce this output:

OP_CONSTANT 1 '10'

◆ disassembleInstruction()

uint32_t disassembleInstruction ( Chunk chunk[static 1],
uint32_t offset )

Prints debug information for an instruction.

Takes a Chunk and a uint32_t (offset) and prints the information about the instruction, located at the given offset. Prints the number of the source lines, from which the instruction was compiled, the type of instruction and additional information (such as the value the instruction refers to, destination of a jump instruction, etc). If the byte specified does not represent a known instruction code, the function prints Unknown opcode, followed by the value of the byte.

Parameters
[in]chunkNon-NULL pointer to the chunk being disassembled.
[in]offsetThe offset from the beginning of the chunk, at which the instruction to be disassembled is located.
Returns
The offset of the next instruction or offset + 1 if the byte was not recognized as a known instruction code.

Prints an invocation instruction.

This function defines the output format for invocation instructions (OP_INVOKE and OP_SUPER_INVOKE). The format is

[command name] ([no. of arguments] args) [method name no. in the constant table] '[method name]'

E.g., for an invocation of a method called "add", that takes 2 arguments and whose name is saved under no. 1 in the chunk's constant table, this function would produce this output:

OP_INVOKE (2 args) 1 'add'

[in]offsetOffset of the instruction from the beginning of the chunk.

The offset of the next instruction (offset + 3).

Prints a jump instruction.

This function defines the output format for instructions that perform various kinds of jumps (OP_JUMP, OP_JUMP_IF_FALSE and OP_LOOP). The format is

[command name] [start point instruction index] -> [destination instruction index]

E.g., for an loop instruction that defines a jump from instruction 28 to instruction 14 this function would produce this output:

OP_LOOP 28 -> 14
Parameters
[in]nameA C string representing the command name.
[in]signDirection of the jump. Positive for forward jumps, negative or zero for backward jumps (loops).
[in]chunkNon-NULL pointer to the chunk containing the instruction to be printed.
[in]offsetOffset of the instruction from the beginning of the chunk.
Returns
The offset of the next instruction (offset + 3).
