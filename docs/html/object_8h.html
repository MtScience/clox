ObjString * copyString ( VM * vm,
uint32_t length,
char const chars[static length] )

Constructs a Lox string.

Takes a VM and an array of chars and creates a new ObjString. This function assumes the caller does not own the source array, so it leaves it unchanged.

Parameters
[in]vmNon-NULL pointer to the virtual machine that will manage the resulting Lox string.
[in]lengthThe length of the string being processed
[in]charsAn array of characters that contains the string data. Does not have to be a null-terminated C string.
Returns
The pointer to the newly-created or previously interned (if available) Lox string.

Constructs a Lox string.

Takes a VM and an array of chars and creates a new ObjString. Unlike copyString(), it assumes the caller does own the source array, so it frees it if an interned string is found.

Parameters

[in]lengthThe length of the string being processed
[in]charsAn array of characters that contains the string data. Does not have to be a null-terminated C string.
Returns
The pointer to the newly-created or previously interned (if available) Lox string.
