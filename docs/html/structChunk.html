Detailed Description

Code chunk type.

A struct that represents a chunk of code. A chunk is compiled from top-level code (a script or REPL input) or a function. A chunk contains its own list of constant values (literal numbers and strings, as well as identifiers). Lox nil, true and false do not count as constants and are instead put into Chunk::code as OP_NIL etc.
