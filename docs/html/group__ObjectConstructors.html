Detailed Description

Lox object construction functions.

These functions take a GC and necessary data and construct a new heap-allocated object value.

String construction is somewhat special and is handled by copyString() and takeString().

Parameters
[in]gcNon-NULL pointer to a garbage collector that will manage the object.
Returns
The pointer to a newly-created structure of appropriate type.
