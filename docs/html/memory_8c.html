void collectGarbage ( GC gc[static 1])

Runs a garbage collection cycle.

This function implements the main garbage collection logic. It marks all the reachable roots, frees unreachable objects (including weak references) and updates the memory threshold (GC::nextGC).

[in]gcNon-NULL pointer to the garbage collector.

void freeObjects ( GC gc[static 1])

Frees all objects.

freeObjects() free all the objects managed in a GC (references to which are kep in GC::objects). If there are several garbage collectors (e.g., when using several VM's in separate threads), this function will have to be called for each of them.

Parameters
[in]gcNon-NULL pointer to the garbage collector, whose managed objects are to be freed.

void * reallocate ( GC gc[static 1],
void * pointer,
size_t oldSize,
size_t newSize )

Handles allocation and freeing of memory.

This is the main memory management function in this project. If the block of memory is to be enlarged, it can trigger a garbage collection cycle. If the new size is 0, the function frees the block.

reallocate() is implemented in terms of free() and realloc(), with all the side effects that result from this.

Parameters
[in]gcNon-NULL pointer to the garbage collector, that manages the memory block.
[in,out]pointerThe pointer to the block of memory to be resized. If NULL, new memory is allocated.
[in]oldSizeCurrent size of the block. Ignored if pointer == NULL.
[in]newSizeDesired size of the block.
Returns
The pointer to resized block or NULL (if the block was freed).
