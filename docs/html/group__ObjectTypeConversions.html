Detailed Description

Object type conversion functions.

These functions take a Value and, assuming it represents a Lox object, extract the pointer to data from it and cast that pointer to specific type.

Parameters
[in]valueThe value to perform type conversion on.
Returns
The pointer to a Lox object type.
