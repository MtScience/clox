uint32_t addConstant ( VM * vm,
Chunk chunk[static 1],
Value value )

Creates a constant in a chunk.

Takes a Chunk and a Value and writes the value into the Chunk::constants field of the chunk. Takes care not to let the garbage collector delete a value too early, by putting it onto the stack of the VM, and popping it after it is safely written into the chunk.

Parameters
[in]vmNon-NULL pointer to the VM governing the chunk.
[in]chunkNon-NULL pointer to the chunk to write the value into.
[in]valueThe value to be written.
Returns
The index of the newly-written value in the chunk's constants array.

Writes a byte to a chunk.

Takes a Chunk and a uint8_t (byte) and writes the byte into the Chunk::code field of the chunk. The byte can be an arbitrary uint8_t value (since this function is also used for writing instruction arguments).

Parameters
[in]gcNon-NULL pointer to a GC structure. To avoid problems with freeing and garbage collection, this should always point to the same structure for a given chunk.
[in]chunkNon-NULL pointer to the chunk to write the byte into.
[in]byteThe byte to be written.
[in]lineThe line number corresponding to the byte being written.
