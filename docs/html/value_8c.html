◆ valuesEqual()

bool valuesEqual ( Value a,
Value b )

Tests values for equality.

Checks whether two Values are equal. For booleans and numbers it uses the regular value comparison; for Lox objects it uses pointer equality (basically functioning like Python's is operator).

This function is marked as [[reproducible]].

Parameters
[in]aLeft operand.
[in]bRight operand.
Returns
Equality test result.

Writes a value to an array.

Takes a ValueArray and a Value and writes the value into the ValueArray::values field.

Parameters
