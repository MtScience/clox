CPU clock function.

An example Lox native function that implements timing. Defined in terms of C's clock() function.

Parameters
[in]argCountNumber of arguments the function takes. Unused.
[in]argsArray of arguments. Unused.
Returns
The result of C's clock() divided by CLOCKS_PER_SEC, wrapped in a Lox value.
