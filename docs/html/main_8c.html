char * readFile ( char const * path)

Reads a file at the given location.

Attempts to open the file, determine the size of its content, allocate memory to hold said content in a string and read the file into that string. If at any point an error happens, the function fails.

Parameters
[in]pathA C string containing the path to the file.
Returns
The pointer to the allocated source string.
