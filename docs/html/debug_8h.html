uint32_t disassembleInstruction ( Chunk chunk[static 1],
uint32_t offset )

Prints debug information for an instruction.

Takes a Chunk and a uint32_t (offset) and prints the information about the instruction, located at the given offset. Prints the number of the source lines, from which the instruction was compiled, the type of instruction and additional information (such as the value the instruction refers to, destination of a jump instruction, etc). If the byte specified does not represent a known instruction code, the function prints Unknown opcode, followed by the value of the byte.

Parameters
[in]chunkNon-NULL pointer to the chunk being disassembled.
[in]offsetThe offset from the beginning of the chunk, at which the instruction to be disassembled is located.
Returns
The offset of the next instruction or offset + 1 if the byte was not recognized as a known instruction code.
